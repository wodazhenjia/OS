# SimOS：题目六模拟操作系统

Java Swing实现的单用户、多道程序模拟系统，包括进程管理、内存管理、设备管理、文件管理和用户接口。最低运行环境为JDK 21；使用更高版本JDK构建时，脚本仍通过 `--release 21` 输出Java 21兼容字节码。

## 运行与测试

在包含 `pom.xml` 的项目根目录操作；IntelliJ IDEA也应直接打开这个目录。设置Project SDK为JDK 21或更高版本，运行 `cn.edu.scau.os.app.SimOsApp`。

macOS / Linux：

```bash
chmod +x run.sh
./run.sh               # 编译、打包并启动界面
./run.sh build         # 仅生成target/simos.jar
./run.sh selftest 600  # 基础自检，模拟600个时间单位
./run.sh test          # 要求回归测试与目录树回归测试
```

Windows（终端为cmd）：

```bat
run.bat
run.bat build
run.bat selftest
run.bat test
```

脚本优先使用 `JAVA_HOME`，macOS会查找已安装JDK，否则使用PATH。Windows也兼容旧项目约定的 `%USERPROFILE%\.jdks\ms-21.0.11`。需要完整JDK中的java、javac和jar。

打包后可运行 `java -jar target/simos.jar`。基础自检与新增回归测试使用临时磁盘，**不会格式化项目中的真实模拟磁盘**。测试进程失败返回非零退出状态。

## 指令集：所有指令均为一个字节

| 编码 | 指令 | 参数范围 |
|---|---|---|
| 0x00～0x63 | x=? | 0～99 |
| 0x64 | x++ | x上界255，达到上界后保持255 |
| 0x65 | x-- | x下界0，达到下界后保持0 |
| 0x66 | end | 发出程序结束中断 |
| 0x80～0x89 | !A? | 时间0～9 |
| 0x90～0x99 | !B? | 时间0～9 |
| 0xA0～0xA9 | !C? | 时间0～9 |
| 其他 | 非法指令 | 进程异常结束并回收资源 |

设备类型放在高半字节，时间放在低半字节。例如 `!A3` 编码为0x83，整体只占一个字节。支持一行一条指令、空白行和 `//`、`#` 注释。设备参数必须是单个数字。

```text
x=5
x++
!A3
x--
end
```

上例的机器码为 `05 64 83 65 66`，共5字节。程序应使用end明确结束；没有end而越过自身分区时，按存储保护异常处理。

## 文件、磁盘与持久化

- 每块64字节，共256块，disk文件大小16384字节。读写使用盘块缓冲和FileChannel，不把整盘内容载入内存。
- FAT共256项，每项一个字节。数据块号5～255均可使用，包括原先与特殊标记冲突的253～255号。
- FAT值：0空闲、1链尾、2坏块、3系统保留，5～255为下一盘块号。
- 目录项固定8字节：名称3、扩展名1、属性1、起始块1、长度2。
- 根目录固定一块、最多8项；子目录按需扩容。空文件也独占至少一个盘块。
- 普通文本内容使用UTF-8，文件长度按真实字节数计算。目录项名称只接受ASCII字母、数字，主名最多3字符，扩展名最多1字符；目录没有扩展名。
- 查找、修改、删除按完整名称区分，例如abc和abc.e可以同时存在。
- 文件系统操作失败时恢复FAT、目录与数据，不泄漏磁盘块。递归删除遇到只读文件时，整次操作回滚。
- 加载时校验循环链、共享盘块、非法目录项、文件长度和泄漏盘块，损坏磁盘会报错，**不会自动格式化**。

### 指导书磁盘布局的矛盾

指导书同时要求FAT占第0、1块、根目录位于第2块，以及256项×1字节的FAT。256字节实际需要4个64字节盘块，两个条件不能同时满足。

本实现保留完整256项FAT，采用FAT块0～3、根目录块4、数据区块5～255。此取舍需在报告中说明并与指导教师确认；不应简单缩成128项，否则无法管理全部256块。

### 启动与旧版迁移

正常启动加载已有 `runtime/disk.img`。只有磁盘不存在时，才创建演示数据；“重新初始化”或format是显式重建操作，会清除模拟磁盘文件与运行状态。

旧版FAT（253/254/255特殊标记）及旧版双字节设备指令会自动迁移。迁移前保留 `runtime/disk-legacy-*.bak` 原盘副本，并保留文件属性。旧版设备时间超过9、指令无法识别或磁盘损坏时拒绝迁移，保留原盘，避免静默改写语义。

已有磁盘的演示程序不会被新版样例覆盖。想观察新的长程序样例，可在确认不再需要现有模拟文件后，使用重新初始化。

## 内存、CPU与设备时序

用户区为实际 `byte[512]`，分区表为链表，支持首次、下次和最佳适配。程序获得分区后装入用户区；CPU根据基址、限长和逻辑PC从该数组取指，不能访问其他进程的分区。尚未获得内存的程序保留暂存副本，内存释放后重新申请并装入。空程序或超过512字节的程序无法运行，不占用PCB。

PCB池共10个，P0为闲逛进程，因此最多9个用户进程同时存在。AX、PC、IR、PSW在CPU中独立保存，切换时与PCB明确交换现场；每次投运获得完整6单位时间片，只有实际执行的进程消耗本单位时间片。

无参 `CPU()` 循环在一个脉冲线程中推进模拟。每个单位：

1. 对本单位开始前已经占用的设备推进倒计时。
2. 在执行新指令前处理I/O、程序结束或时间片中断。
3. 随机到达新进程；就绪进程让闲逛进程让位。
4. 最多执行一条原子指令，结算实际执行者的时间片。
5. 系统时钟增加1。

结束中断优先于同一进程的时间片中断。结束或异常会回收PCB和内存；异常不会同时显示为正常完成。

A设备2个，B/C各3个。使用者在自己的I/O完成前保持阻塞。等待分配的进程单独进入FIFO队列；设备释放后立即分配给队首，队首继续阻塞直至自己的I/O完成。排队申请不重复执行。零时间I/O立即完成，不占设备。

首次申请设备的单位不会提前扣除该设备时间；阻塞后新投运的进程也不会被扣除旧进程的时间片。进程撤销时持有的设备同样会移交等待者。

随机到达间隔为2～6个模拟时间单位，程序随机选择；固定种子可复现实验。菜单可关闭自动到达，手工运行程序观察行为。独立脉冲线程与Swing界面线程通过同一把内核锁协调，时间单位调整不重启CPU线程。

## 界面与命令

界面显示系统时钟、运行进程、时间片、就绪与阻塞队列、指令、中间与最终结果、彩色内存、目录树、256块磁盘状态、PCB表和设备占用/等待情况。

菜单提供暂停/继续、单步、实时速度调整、自动随机创建进程开关、汇编编辑器、分配算法选择和重新初始化。单步后保持暂停，便于逐条观察。日志按递增序号追加，达到保留上限后仍持续更新；界面日志长度也有限制。目录与可执行文件列表仅在文件系统修改后重建。

| 命令 | 用途 |
|---|---|
| create <路径> [内容] | 创建文件；.e内容汇编为机器码 |
| delete <路径> | 删除文件 |
| type <路径> | 普通文本回读或.e反汇编 |
| copy <源> <目标> [扩展名] | 拷贝文件 |
| mkdir <路径> | 建立目录 |
| rmdir <路径> | 删除空目录，非空报错 |
| run <.e路径> | 创建进程运行程序 |
| deldir <路径> | 递归删除目录 |
| change <路径> <普通\|只读\|系统> | 修改属性，保留目录类型位 |
| dir / ls | 显示目录树 |
| format | 重建演示磁盘与运行状态 |
| help | 命令帮助 |

create是文件创建命令，run才是进程创建命令。文件命令本身不创建模拟进程，符合题目六的简化要求。

```text
create /aa/new.e x=5|!A3|x++|end
type /aa/new.e
run /aa/new.e
create /doc/uni 中文文本
type /doc/uni
```

只有.e源码中的“|”会转换成换行，普通文本中的“|”按原样保存。路径支持/或反斜杠，正确处理.与..。chdir、move、fdisk尚未实现，属于题目的可选命令。

汇编编辑器提供源码、编译清单、反汇编、十六进制转储和按行显示的错误；编译保存后可选择立即运行。源码存档使用UTF-8，保存在 `runtime/PmPt.asm`，与模拟磁盘文件分开。存档失败不会显示成保存成功。

## 验证范围

`--selftest 600` 覆盖22项基础检查。新增 `RequirementsRegressionTest` 使用精确断言，覆盖：

- 全部合法赋值及设备参数的单字节编码、非法编码与参数边界。
- 64/65字节跨块、全部251个数据块、满盘回读、磁盘满和根目录满的回滚。
- 同主名不同扩展名、只读保护、目录属性保留、递归删除回滚、名称与路径校验。
- UTF-8与可执行文件跨启动保存、旧版FAT和字节码迁移、迁移备份及损坏磁盘拒绝加载。
- 三种内存算法、真实内存内容、地址保护、分区合并、快照隔离、内存等待后装入。
- 精确6条指令轮转、寄存器恢复、设备倒序完成、饱和设备FIFO移交、持有者撤销。
- 全状态初始化、空程序和超大程序不泄漏PCB、日志保留上限、随机到达及固定种子复现。
- 并发编辑/创建与快照读取、CPU线程关闭。
- 原有DirectoryTreeRegressionTest继续验证展开、折叠、选择与目录变化。

测试时持续检查运行/就绪/阻塞队列互斥、设备持有者状态、内存总量与进程回收等不变量。

## 项目结构与交付

```text
src/main/java/cn/edu/scau/os/
  app/          入口与基础自检
  instruction/  单字节指令与汇编器
  disk/         盘块I/O、FAT、目录、事务和旧版迁移
  storage/      512字节内存及链表分区表
  process/      PCB及调度队列
  cpu/          寄存器、中断及原子指令执行
  device/       独占设备及FIFO等待
  kernel/       进程原语、同步、快照、命令和演示数据
  ui/           主窗口、目录树及汇编编辑器
src/test/java/  要求与目录树回归测试
runtime/       模拟磁盘、源码存档和迁移备份（本机生成，Git忽略）
参考资料/       本机课程资料（通过.git/info/exclude忽略）
```

首次启动准备5个目录、18个文件及10个可执行文件。`lng.e` 为72字节跨块程序，`mem.e` 为110字节内存演示程序。
